# Regime-Conditional Mixture-of-Experts for Cross-Sectional Equity Prediction

Code, data, checkpoints and logs for the ICTCS 2026 paper (Paper ID 889).

A causal, rule-based gate assigns each stock-day to a trend, mean-reversion or
choppy regime. One LightGBM expert per regime is trained only on that regime's
rows and compared with one pooled LightGBM model trained on all rows, under the
same folds, features, hyperparameters and seed.

## Reproduce

```bash
pip install -r requirements.txt
python -m pytest -q tests                 # 51 tests
python tools/run_with_checkpoints.py      # ~10 minutes on CPU; writes outputs/replay/
```

The replay exits non-zero if any statistic differs from the published JSON by more
than 1e-6. The run committed in `outputs/replay/` reproduced all 51 of 51 statistics
over 25 folds (2013-01-04 to 2025-07-04) with seed 42.

## Checkpoints

Each file is a LightGBM model in text form, gzip-compressed. `manifest.json` lists,
for every model, the fold, regime, number of training rows, training date range,
feature columns, ranking configuration and file sha256.

```python
import gzip, lightgbm as lgb
booster = lgb.Booster(model_str=gzip.open("outputs/replay/checkpoints/fold_01_pooled.txt.gz", "rt").read())
```

## Implementation details as run

- Model: LightGBM LambdaRank (`ranking.train_ranker`), relevance grades 0-9 from the
  5-session forward cross-sectional rank; 500 rounds, learning rate 0.03, 31 leaves.
- Features: the `price_only` set in `ranking.py` (44 candidate columns), after
  dropping columns that are mostly missing, constant, or flagged by the drift
  monitor on the fold's own training data. The per-fold count (16 to 39) is in
  `manifest.json`.
- Purge: the final 5 observed sessions (`RANK_LABEL_HORIZON = 5`) before each test
  window are excluded from training.
- Folds: expanding window, first 3 years of history as initial training, 6-month
  test windows, 25 folds.
- Costs in portfolio simulations: 10 bps per unit one-way turnover plus 5 bps slippage.
- Universe: 200 NSE names screened at a single snapshot date, 190 with enough
  history. Not point-in-time; survivorship bias applies (see the manifest).

## Not included

- Scripts for serial-dependence-robust inference (HAC, stationary bootstrap) and for
  the regime-threshold / HMM sensitivity checks are not in this repository. The
  result JSONs here contain independence-based t-statistics.
- The portfolio result JSONs are saved outputs of the functions in
  `core/forecast/regime_mixture.py`; they are not regenerated by the replay above.
- Raw price downloads and any credentials are not included. The 2025-09 onward data is
  not included.
